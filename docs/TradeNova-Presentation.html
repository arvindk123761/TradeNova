Project Presentation01
01 / Problem

Making investment workflows easier to understand and use

The challenge

New investors often need multiple disconnected tools to track markets, manage funds, place trades, and review performance.

The opportunity

Build one accessible platform that combines market discovery, simulated trading, portfolio tracking, wallet management, and investment categories.

TradeNova06
06 / Security & Data

Designed around authenticated user actions

Authentication

  • Passwords are hashed with bcrypt.
  • JWT tokens protect user routes.
  • Authorization accepts Bearer tokens.
  • Users access their own wallet, trades, and holdings.

Persistence

  • MySQL stores users, wallets, stocks, orders, transactions, watchlists, IPO applications, activities, and investments.
  • Portfolio and investment actions update balance and history.
  • Secrets and dependencies are excluded from Git.

TradeNova09
09 / Limitations & Future Scope

A strong prototype with clear next steps

Current limitations

  • Market prices are simulated.
  • No live broker or exchange connection.
  • No real payment gateway or settlement.
  • Investment categories use demo catalog data.

Future scope

  • Integrate live market data APIs.
  • Add role-based admin authorization.
  • Add real broker and payment integrations.
  • Add sell, valuation, and reporting for every investment category.
